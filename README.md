Blinkit Sales Analysis Dashboard (Excel)

Project Overview

This project focuses on analyzing Blinkit’s retail sales data using Microsoft Excel. The goal is to identify important business trends, evaluate outlet performance, and generate meaningful insights through an interactive dashboard.

Objectives

* Analyze overall sales performance.
* Identify top-performing item categories.
* Compare outlet sales and performance.
* Understand customer preferences based on item types.
* Track key business performance indicators (KPIs).

Tools & Technologies

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Cleaning
* Dashboard Visualization

Key Features

* Interactive sales dashboard.
* KPI cards for business performance.
* Category-wise sales analysis.
* Outlet-wise performance comparison.
* Filter-based data exploration.

Key Insights

The dashboard helps understand sales patterns, outlet performance, product demand, and business trends.
